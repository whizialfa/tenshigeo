# TenshiGeo

Geospatial studio site — selected work, analysis packages, request box, and a decorative print studio.

**Live (GitHub Pages):** https://whizialfa.github.io/tenshigeo/

```bash
npm install
npm run dev          # full app with APIs (localhost:3000)
npm run build:pages  # static export for GitHub Pages
```

Checkout, PayPal, geocode proxy, and order downloads need Node (`npm run dev` or a full host). The Pages build is the public portfolio.
